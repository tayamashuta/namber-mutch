# Namber Mutch

ブラウザで遊べる日本語のNumber Matchパズルです。React・TypeScript・Viteで構成し、ゲームルールをUIから独立させています。

## 開発

```sh
npm install
npm run dev
```

## 確認コマンド

```sh
npm test       # ゲームルールのユニットテスト
npm run lint   # Oxlint
npm run build  # TypeScript検査と本番ビルド
npm run preview # 本番ビルドのローカル確認
```

## 遊び方

- 同じ数字、または合計10になる数字のペアを選ぶと消去できます。
- 新しいゲームでは、ペア候補からシャッフルした35個の数字で盤面を作ります。
- ペアは、同じ行・縦・斜めの同一直線上で間のマスが空いている場合、または行末と次行の先頭でも選べます。
- 「数字を追加」は手詰まりでなくても使え、盤面に残っている数字をもう一度追加します。
- 「ヒント」で候補を表示、「ひとつ戻す」で直前の操作を取り消し、「新しいゲーム」で盤面をリセットできます。
- `H` はヒント、`U` はUndo、`N` は新しいゲームのキーボードショートカットです。
- ベストスコアはこのブラウザのlocalStorageに保存されます。アカウントやオンラインランキングはありません。

## 構成

- `src/game/`: ペア判定、ゲーム状態、Undo、ユニットテスト
- `src/App.tsx`: ゲーム画面と操作
- `src/App.css`・`src/index.css`: レスポンシブUI

## 公開

GitHubの`main`ブランチに接続したVercelプロジェクトからデプロイできます。Viteのビルドコマンドは`npm run build`、出力ディレクトリは`dist`です。
